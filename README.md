Contest Manager App 🏆
Overview:
A MERN (MongoDB, Express, React, Node.js) stack application for managing contests. This app allows users to view and add contests, as well as nominate participants. Built with React and TypeScript for the frontend, Express and Node.js for the backend, and MongoDB for data storage.

Key Features:
Contest Display: Browse and view a list of contests with relevant details.
Contest Creation: Add new contests with ease using the intuitive interface.
Participant Nominations: Nominate participants for contests, enhancing engagement.

Technologies Used:
Frontend: React, TypeScript, Axios
Backend: Express, Node.js
Database: MongoDB
Tooling: Docker for MongoDB image, MongoDB Compass for database management, Webpack for bundling.
